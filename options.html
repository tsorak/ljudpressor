Ljudpressor

Click the extension’s toolbar button for a dropdown with this tab’s on/off switch and a strength slider. Use Advanced settings in that dropdown to reopen this tab. A green ON badge means compression is running. Settings apply to every active tab and are saved for next time.

Compression strength

Move this slider to use the simple preset. Stronger settings reduce the difference between quiet and loud sounds.

Advanced controls

Changing an advanced control overrides the strength slider. Move the slider again to return to simple mode.

Positive output gain can make audio very loud. Start at 0 dB.

Capture must be started separately for each tab, and won’t resume automatically after restarting the browser.
